B. 문법 핵심

1) -아요/어요 : 동사를 현재형으로 말해요.

공부하다 → 공부해요 / 먹다 → 먹어요 / 보다 → 봐요 / 듣다 → 들어요

2) 을/를 : 동작의 대상을 나타내요.

받침 있음: 밥을 먹어요. · 받침 없음: 피자를 먹어요.

공원 / 마트 / 백화점 / 여기
공원에 가요. · 마트에 가요. · 여기에 있어요.
빵 / 라면 / 과일 / 커피 / 차 / 우유
빵을 먹어요. · 커피를 마셔요. · 과일을 사요.
사과 / 포도 / 케이크 / 김밥 / 아이스크림

신발 / 구두 / 화장품
백화점에서 신발을 사요.

B. 문법 핵심

1) 장소 + 에 가요 : 이동하는 장소를 말해요.

학교에 가요. / 카페에 가요.

2) 명사 + 하고 : 두 가지 이상을 연결해요.

빵하고 우유를 사요. / 커피하고 차를 마셔요.
